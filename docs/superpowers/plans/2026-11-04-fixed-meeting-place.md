# 정해진 장소로 모이기

승인된 홈 예시를 구현한다. 기존 그림·카드·색상을 유지하고, 카드 위에 `중간지점 찾기`, 아래에 별도 `정해진 장소로 모이기` 진입을 둔다. 장소 선택 다음에 직접/함께 입력을 선택한다. 기존 추천 흐름은 유지한다.

## 계약

- 공통 장소: `{ name, address, x, y }`. 직접 입력은 세션에 저장, 함께 입력은 방 서버 상태에 저장한다.
- 직접 입력은 `/meeting` → `/meeting/individual` → `/meeting/list`. 함께 입력은 `/meeting/together`로 방을 생성한 뒤 기존 공유방 목록·초대 URL을 이용한다.
- 고정 장소는 출발지 한 곳부터 계산 가능하며 기존 중간지점은 두 곳 이상을 요구한다.
- 새로운 `location-destination` 함수가 지정 장소까지의 경로만 조회한다. 참가자 인덱스를 유지한 성공/조회 불가 결과를 기존 `location_result.request_info`에 저장한다. 후보·투표·확정은 없다.
- 함께 입력은 기존 실행 ID/만료/실패 복구를 재사용한다. 함수가 방장 capability와 실행 ID로 서버 출발지·장소를 조회한다. 결과 게시 시 같은 방·실행·입력인지 검증한다.
- 장소 변경은 방장만 가능하다. 진행 중 계산은 변경을 막고 완료된 방의 장소 변경은 이전 결과 연결을 지우고 입력 상태로 돌아간다. 출발지 개인 수정 권한은 유지한다.
- 실패한 경로는 시간을 만들지 않는다. 성공 경로와 카카오맵 앱 우선/웹 길찾기, 재계산 수단을 제공한다.
