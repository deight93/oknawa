# 카카오맵 길찾기

확정 전 결과 패널을 펼치면 참가자별로 **카카오맵 길찾기**와 **웹으로 보기**를 제공합니다. 로그인 없이 자기 이름과 출발지를 확인해 선택합니다. 현재 후보의 좌표와 참가자의 이동수단을 전달하며 추천·투표 결과는 바꾸지 않습니다.

- Android는 카카오맵 스킴을 가진 Intent와 `browser_fallback_url`로 앱을 시도합니다.
- iOS와 iPadOS는 `kakaomap://route`로 앱을 시도합니다.
- 모바일에서 화면이 계속 활성 상태이면 약 2초 뒤 웹으로 이동합니다. 앱 전환, 창의 포커스 이탈, 타이머 정지, 후보 변경, 패널 접기, 다른 참가자 선택, 웹 링크 선택, 컴포넌트 해제 시 대기 중인 이동을 취소합니다.
- 데스크톱과 보조키 클릭은 일반 웹 링크로 열립니다. **웹으로 보기**는 항상 새 탭에서 웹 주소를 엽니다.

앱 설치 여부를 웹에서 확실하게 감지할 수는 없습니다. iOS 실행 확인창이나 인앱 브라우저가 전환을 막으면 자동 이동을 취소할 수 있으므로 웹 링크를 함께 제공합니다. 카카오맵 자체의 앱 열기 안내와 실제 경로·소요시간은 카카오맵에서 결정합니다. 설치된 앱으로의 전환은 실제 기기에서 별도 확인해야 합니다.

## 경로 데이터

서버가 보존하는 참가자 순서로 출발지를 연결합니다. 이름은 중복될 수 있어 이름만으로 찾지 않습니다. 참가자 수·이름·지역의 순서가 맞지 않거나 좌표가 없으면 길찾기 링크를 표시하지 않습니다. 출발지·도착지 주소와 좌표는 링크를 누를 때 카카오맵으로 전달합니다.

| 이동수단 | 웹 `by` | 앱 `by` |
| --- | --- | --- |
| 대중교통 | `traffic` | `publictransit` |
| 자동차 | `car` | `car` |
| 도보 | `walk` | `foot` |

좌표는 위도·경도 순서입니다. 장소 이름은 경로 구분 문자가 섞이지 않도록 인코딩합니다. 추가 API 요청이나 키는 필요하지 않습니다.

## 검증

`pnpm test:app`에서 URL 인코딩, 이동수단, 동명이인, 좌표 유효성, 타이머 취소·정지·중복 실행을 검사합니다. 로컬 브라우저 검증은 실제 결과 컴포넌트와 가상 참가자 데이터를 사용하고 외부 지도 요청을 가로챕니다. 실제 앱이 열렸다는 검증은 아닙니다.

배포 미리보기에서 Android Chrome과 iOS Safari 각각 앱 설치·미설치 상태를 확인합니다. 대중교통·자동차·도보의 출발지와 도착지, 앱에서 뒤로 돌아오기, 실행 확인창 취소, 후보 변경, 웹 링크 사용을 확인합니다. 인앱 브라우저에서 앱이 열리지 않으면 웹 링크로 이동 가능한지도 확인합니다.
